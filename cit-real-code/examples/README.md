# CIT examples

One runnable program for each chapter of the **Look 'n learn** guide (the `Look 'n learn` folder next to this one). Open a file in VS Code and press the **Play** button.

| File | Topic | Guide chapter |
| --- | --- | --- |
| `01-hello-world.cit` | printing, colors, comments, `input` | 1 |
| `02-variables-and-types.cit` | `let`, `let mut`, types, empty variables, scope | 2 |
| `03-operators.cit` | math, comparing, `&&` `\|\|` `!`, `in`, `+=`, `++` | 3 |
| `04-strings.cit` | templates, multi-line strings, string methods | 4 |
| `05-conditions.cit` | `if`, `elseif`, `else`, `switch` | 5 |
| `06-loops.cit` | `while`, `do-while`, `for` with steps, `for-in` | 6 |
| `07-lists.cit` | lists, 18 methods, `map` / `filter` / `reduce` | 7 |
| `08-dictionaries.cit` | dictionaries and their 11 methods | 8 |
| `09-functions.cit` | parameters, lambdas, closures, `defer` | 9 |
| `10-classes.cit` | classes, inheritance, `super()`, `?.` | 10 |
| `11-errors-and-safety.cit` | `try` / `catch` / `throw`, fallbacks | 11 |
| `12-built-in-functions.cit` | `cast...`, `range`, `min`, `max`, `sum`, `len`, `random`, `randint` | 12 |
| `13-guessing-game.cit` | a small game using input, random numbers and loops | 3-12 |
| `14-modules.cit` (+ `lib/greeter.cit`) | `import` | 13 |
| `15-mini-project.cit` | a grade book using many features together | all |

Tips:

- Change a line, run it again, and see what happens. That is the fastest way to learn.
- `Shift+Alt+F` formats your code.
- If something breaks, the error message tells you the line and what went wrong (see chapter 11).
